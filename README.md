# 💊 Medicine Reminder Web App

🔗 **Live Website:** https://medicine-reminder-2.onrender.com/

Medicine Reminder is a simple and user-friendly web application that helps users **schedule and manage medicine reminders** so they don’t miss important doses.

---

## 🚀 Features

- ➕ Add medicine reminders with:
  - Medicine name
  - Time
  - Email address
- 📋 View all scheduled reminders
- ✅ Reminder status indicator (Sent / Pending)
- 🗑️ Delete individual reminders
- 🧹 Clear all reminders at once
- 🌐 Fully deployed and accessible online

---

## 🧠 How It Works

1. Open the website using the live link.
2. Click **“Add Reminder”**.
3. Enter:
   - Medicine name
   - Reminder time
   - Email address
4. Submit the form.
5. The reminder appears in the list with its status.
6. You can delete reminders anytime or clear all.
